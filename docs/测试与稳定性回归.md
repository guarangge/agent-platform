# 测试与稳定性回归

## 1. 目标

自动化回归优先验证通用 Agent 平台主链，不依赖高考等单一业务数据，不依赖第三方 LLM 或外部 MCP Server 的网络稳定性。

## 3. 本地执行

macOS / Linux，在项目根目录 `/path/to/agent` 执行：

```bash
mvn test
STABILITY_REPEAT=3 bash scripts/test/run_agent_stability_suite.sh
PLATFORM_E2E_POSTGRES_IMAGE=pgvector/pgvector:pg16 bash scripts/test/run_platform_e2e.sh
cd frontend-web && npm run build
npx playwright test tests/e2e/runtime-event.spec.ts
npx playwright test tests/e2e/replay.spec.ts
```

平台 E2E 会自动完成以下操作：

1. 执行 `mvn clean package`，避免旧 `target/classes` 残留 migration 进入发布包。
2. 启动临时 pgvector 容器，对两个空数据库执行全部 Flyway migration。
3. 启动隔离的 `registry-center`、`agent-core` 和 Mock LLM，测试结束后自动清理。
4. 通过真实 API 创建 Model、Prompt、Agent 和 Conversation，并注册、加载高考与图片理解两个 Runtime Plugin Jar。
5. 验证登录、Context、LLM Decision、LLM Planner、Plan、Task/Step、Reply、Trace 和拓扑。
6. 通过 multipart 上传真实 PNG，执行带图片的异步 Run，验证 OpenAI-compatible 多模态 `content` 数组以及 `input.attachment.resolved` 持久化事件不含 Base64。
7. 验证两轮历史消息连续性，以及持久化异步队列的入队、Worker 执行和指标。
8. 构建并运行 Java SDK 独立示例 Jar，验证其通过真实双服务协议完成异步 Run 和 Runtime Event 消费。

脚本默认使用 `pgvector/pgvector:pg16`。本地已有其他兼容版本时，可通过 `PLATFORM_E2E_POSTGRES_IMAGE` 覆盖；CI 固定验证默认版本。

Windows PowerShell，在项目根目录执行 Maven 全量测试：

```powershell
mvn test
Set-Location frontend-web
npm run build
```

`run_agent_stability_suite.sh` 由 CI 在 Linux Runner 中执行。Windows 本地可以重复执行对应的 Maven `-Dtest` 命令。

Windows 上的平台 E2E 建议在启用 Docker Desktop 的 WSL2 中，从项目根目录执行同一 Bash 命令。

Token 失效跳转回归在 `frontend-web` 目录执行：

```bash
npx playwright test tests/e2e/auth-expiration.spec.ts
```

该用例验证本地 Token 被清理、浏览器跳转 `/login`，并将原站内地址保存到 `sessionStorage` 供登录成功后恢复；普通 HTTP 403 不属于认证失效，不应触发该流程。

## 4. Agent 通用状态 schema

会话状态由 Agent `metadata.dialogState.slots` 声明，不在核心代码写入业务词表。例如：

```json
{
  "dialogState": {
    "enabled": true,
    "slots": [
      {
        "key": "ticketId",
        "label": "工单号",
        "type": "string",
        "required": true,
        "aliases": ["Ticket"],
        "extractionPattern": "(?:工单号|Ticket)[：:=\\s]+([A-Z]+-\\d+)",
        "extractionGroup": 1,
        "overwritePolicy": "keep_existing",
        "conflictPolicy": "mark_conflict"
      }
    ]
  }
}
```

存在可运行 Model 时优先按 schema 调用 LLM 提取；LLM 不可用或失败时，按 `enumValues / extractionPattern / aliases / type` 执行确定性降级。
