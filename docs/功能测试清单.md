# 功能测试清单

## 1. 使用说明

用途：

1. 用于对当前通用 Agent 平台做人工功能回归
2. 按模块逐条执行，记录“实测结果 / 问题备注”
3. 默认以管理后台页面 + 已接通后端接口为测试入口

建议执行顺序：

1. 基础配置类
2. 资源管理类
3. 会话执行主链
4. 治理与观测类
5. 评测与回归类

建议记录规则：

1. `通过`：功能符合预期
2. `失败`：功能不符合预期
3. `阻塞`：因前置数据、环境或权限问题无法继续
